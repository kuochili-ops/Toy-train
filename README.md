𓃥 白六小火車 (White 6 Train Explorer)
這是一項基於 Three.js 開發的 3D 動態鐵道場景網頁應用程式。專案以精緻的低多邊形（Low-Poly）山體造景、動態季節變換、現代建築風隧道結構，搭配環繞式鐵道與自定義動態招牌，呈現流暢且具互動性的視覺體驗。
✨ 主要特色
 3D 互動場景：利用 Three.js 與軌道控制器（OrbitControls）建構全方位旋覽視角。
 四季山體切換：支援春、夏、秋、冬動態色彩變換，完美搭配條狀結構山體與主山丘。
 動態招牌輪播：具備可自訂文字與字型的即時 Canvas 招牌，火車行經特定角度時自動切換下一則訊息。
 流暢鐵道與隧道結構：精準計算過彎半徑與拱門結構，確保火車與動態模型順暢運行、無視覺穿透或碰撞。
